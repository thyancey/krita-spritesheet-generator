Spritesheet Generator

The Spritesheet Generator exports the frames in the animation timeline as a spritesheet PNG, along with a JSON metadata file for use in game engines such as Godot.

Usage

Open via Tools → Scripts → Spritesheet Generator.

Options

File path: The file path the spritesheet will be exported to. Use the Browse button to pick a location. A .json metadata file is always written to the same folder with the same base name.

Spritesheet layout: How sprites are arranged in the sheet.

  • Rows: Fills each row before moving to the next.
  • Columns: Fills each column before moving to the next.
  • Horizontal Strip: All sprites in a single row.
  • Vertical Strip: All sprites in a single column.

Auto calculate size: Automatically determines the number of rows and columns. Disable to set them manually.

Sprite dimensions:

  • Width / Height: Target size per frame. If different from the document size, sprites are scaled on export.
  • Filter: Scaling algorithm used when resizing.
  • Padding: Transparent border added around each frame to prevent bleeding.

Ignore empty frames: When enabled, only frames that contain keyframes on animated layers are exported. Hold durations are derived from the gap between keyframes. When disabled, every frame in the range is exported at uniform duration.

Layers to export: Top-level layers to include in the composite. Uncheck any layer to exclude it.

Animation Markers (Multiple Animations)

By default the entire timeline is exported as a single animation named default. To export multiple named animations from one document, use animation marker groups.

Setup

Create a Group Layer (Layer → Quick Group, or Ctrl+G) for each animation and name it using the pattern:

A_animationname:startframe-endframe

Examples:

  • A_idle:0-18 — exports frames 0 to 18 as an animation named idle
  • A_walk:19-34 — exports frames 19 to 34 as an animation named walk
  • A_walk_cycle:19-34 — underscores are fine; exported as walk_cycle
  • A_death:35-50:once — plays once instead of looping (see below)

Place your art layers inside the marker group. All visible layers composite normally — the group name is purely metadata.

A typical layer panel looks like this:

[Group]  A_idle:0-18
    └─  face
    └─  legs
    └─  body
[Group]  A_walk:19-34
    └─  face
    └─  legs
    └─  body
[Layer]  Background

Looping

Animations loop by default. To make an animation play once and stop, append :once to the group name:

A_death:35-50:once

Ignore Empty Frames with Markers

When Ignore empty frames is checked, the exporter scans the child layers inside each marker group for keyframes. Only frames where a keyframe exists are exported, and the gap between keyframes defines the hold duration. This is the recommended setting when your animations use holds (e.g. a 4-drawing walk cycle spread across 24 frames).

When unchecked, every frame in the marker range is exported at uniform duration.

JSON Output

The exported .json file contains one entry per animation with frame indices, durations, and loop settings. It is designed to be consumed by the companion Godot importer plugin — see the Godot addon README for details.
